# RAIIN

Uma experiência simples e minimalista de chuva, criada para relaxar, ouvir e aproveitar a atmosfera.

## Como funciona

Ao entrar no RAIIN, um **Place** é exibido com um background cinematográfico representando um local com chuva. Uma pequena lista de Places permite alternar entre diferentes ambientes.

O som da chuva começa após a primeira interação do usuário com a página, já que os navegadores bloqueiam a reprodução automática de áudio. Depois de iniciado, o áudio permanece em loop infinito.

A interface também possui uma pequena linha de frequência que reage em tempo real ao áudio da chuva, criando uma resposta visual sutil.

A proposta do RAIIN é manter a experiência simples e enxuta. Não existem controles de pausa, reinício, volume ou troca de tipos de chuva.

## Recursos

- Backgrounds cinematográficos de diferentes Places
- Seleção de Places
- Áudio de chuva em loop infinito
- Linha de frequência reativa ao áudio
- Tab title dinâmico
- SEO básico
- Código e estrutura de pastas organizados

O RAIIN segue uma ideia simples: **escolha um lugar, ouça a chuva e relaxe.**
